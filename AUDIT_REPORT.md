# Release Audit — 1.0.0

Audit date: 2026-10-18

## Verified

- Production build completes on Next.js 16.4.2.
- ESLint completes with zero errors and zero warnings.
- No committed `.env` file, private key, database credential, or API token was detected.
- Every Server Action authenticates the caller through the shared workspace context.
- Project, task, and client mutations are scoped to the authenticated workspace.
- Workspace metadata changes require the OWNER or ADMIN role.
- Untrusted IDs, enums, strings, email addresses, and numeric values are validated server-side.
- Passwords are hashed with bcrypt cost 12.
- Security response headers disable framing, MIME sniffing, and unused sensitive browser features.
- MongoDB schema includes unique identity/workspace constraints and relationship indexes generated by Prisma.
- Clean-machine, Vercel, and Docker/VPS setup paths are documented.

## Dependency note

Runtime critical vulnerabilities reported against the previous Next.js and NextAuth versions were removed by upgrading to patched releases. Prisma 6.19 remains pinned because Prisma's official documentation states that Prisma 7 does not support MongoDB. npm may report a development-only advisory in the Prisma CLI dependency tree; the CLI is not imported by or shipped in the standalone production server. Reassess when a stable MongoDB-compatible Prisma release is available.

## Review limitations

Automated checks and this report reduce risk but do not guarantee defect-free software. Operators remain responsible for secure environment variables, HTTPS, database backups, access logging, dependency monitoring, and testing after customization.
